# vd-macan — agent orientation

Public data + analysis repo for the Macan S instrumentation project
(github.com/adamlin1009/vd-macan). The full rulebook lives at
`~/Documents/pit-wall/RULES.md`. **Read it before changing anything.**
Launch tooling for multi-agent work: `~/Documents/pit-wall/bin/launch`.

Non-negotiables, inline (details and the rest in RULES.md):

- `data/**` raw files (WIT*.TXT, racebox.csv, SHA256SUMS) are
  EVIDENCE: append-only, never modified, never deleted. Processed
  outputs are regenerated by scripts only. `notes.md` takes dated
  appends, not rewrites of history.
- `tools/day1_analysis.py` generates the site's day-1 post.
  `POST_TEMPLATE` must stay a raw string (`r"""`); a plain literal
  corrupts LaTeX (`\varphi` becomes a vertical tab). Regenerate with
  `python3 tools/day1_analysis.py --post <website>/content/log/2026-08-16-six-runs-two-damper-maps.md`.
- Post prose rules apply to everything publish-bound here (thread
  drafts, docs that feed posts): human voice, no em dashes,
  "AHRS IMU" never "puck", no brake-jab mentions, honesty never cut.
- The IMU's known quirks are characterized, not folklore: 200 Hz
  frames but ~104 Hz distinct accel / ~50 Hz gyro (dedupe before
  spectra), clock ~2% slow with per-power-on offset (sync by envelope
  cross-correlation against the RaceBox). See `docs/shakedown.md`.
- Agents work in worktrees under `work/` (gitignored) on
  `agent/<slug>` branches. Never edit the main working tree, never
  push `main`. Do not add AI co-author trailers unless the owner
  explicitly requests one.
